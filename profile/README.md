<h2>一、地址属性参数</h2>
<p>第一看 ASN 归属。查询结果应显示运营商家宽，显示云厂或托管商的，就不是住宅段。</p>
<p>第二看类型标注。住宅、ISP、机房三类在公开库里标注不同，买之前自己查一遍，别只看商家页面。</p>
<p>第三看历史。地址是否出现在公开滥用库里，命中多的段即使便宜也别碰，后续验证会很频繁。</p>

<h2>二、性能参数</h2>
<p>延迟看往返，从你所在网络到落地，两百毫秒以内算正常，超过三百毫秒日常操作会明显卡顿，买前先测再定。</p>
<p>带宽看独享值，不看峰值。十兆独享能覆盖多数后台操作，二十兆以上才适合素材上传。</p>
<p>抖动比均值更值得看。抖动长期超过三十毫秒，视频会议和长连接都会出问题。</p>
<h2>三、可用性参数</h2>
<p>在线率要写进合同，月度百分之九十九点五起步。只写稳定的，出故障时没有依据。</p>
<p>并发连接数容易被忽略。后台系统常开十几个长连接，上限太低的代理会随机断流。</p>
<h3>参数优先级排序</h3>
<p>地址属性第一，可用性第二，带宽第三，延迟第四，价格最后。顺序颠倒，便宜买回来的往往是麻烦。</p>

<h2>四、接入方式参数</h2>
<p>协议支持 HTTP 与 SOCKS5 两种最常见。浏览器和多数工具都支持 SOCKS5，兼容性更好。</p>
<p>认证方式看是账号密码还是来源白名单。白名单要固定本地出口地址，家宽动态地址容易失效。</p>
<p>是否支持多设备同时接入，要问清并发设备数。按设备收费的方案，多设备成本上升很快。</p>
<h2>五、计费参数</h2>
<p>按地址月付、按流量、按并发三种算法，适用面不同。长期固定业务用按地址月付最直观。</p>
<p>注意最低消费与超量规则。有的套餐设最低流量，用不到也照收；有的超量直接限速。</p>

<h2>六、把参数表读成一句话</h2>
<p>一张合格的参数表应该能回答三个问题：这段地址是什么属性、跑起来有多稳、出了问题谁负责。答不上来的，参数再多也没用。</p>
<p>试用期按三条测：查归属、跑满带宽十分钟、连续挂二十四小时看断线次数。数据留档，续费时就是依据。</p>
<h3>哪些参数可以妥协</h3>
<p>延迟和峰值带宽可以适当妥协，住宅出口本来就不是为低延迟设计；地址属性与在线率不能让。</p>
<h3>参数表的常见缺项</h3>
<p>很少有服务商主动写并发上限和超量规则。这两项不问，用到中途才发现限制，迁移成本比换套餐高。</p>
<h2>常见问答</h2>
<h3>问：固定 IP 住宅代理的延迟多少算正常？</h3>
<p>答：跨太平洋往返两百毫秒上下属常见区间。低于一百五十毫秒偏快，高于三百毫秒日常操作会有明显卡顿。</p>
<h3>问：怎么确认买到的是住宅段而不是机房段？</h3>
<p>答：查 ASN 归属与地址类型标注，两项都应指向运营商家宽。商家页面上的描述不能作为依据。</p>
<h3>问：并发连接数重要吗？</h3>
<p>答：重要。后台系统会同时开多个长连接，上限低的代理表现为随机断流，很难排查。</p>
<h3>问：按流量还是按月买更合适？</h3>
<p>答：长期稳定跑量按月更可控，峰值型、间歇型任务按流量更省。先估月均占用再决定。</p>
